# Rootwork brand specification

## Identity

Rootwork uses the approved target-and-arrow mark from the supplied master artwork.

- Indigo `#1800AD` — primary brand/action color
- Light blue `#AFE2FF` — launch and homescreen icon background
- White — surfaces

The product is light-only. Open Sans is the primary UI and wordmark typeface with system fallbacks.

## Brand assets

Runtime and install assets are deliberately separated:

- `brand/rootwork-mark.png` — transparent 512×512 runtime mark. No background, shadow, blur, glow, replacement SVG, or CSS image hack.
- `brand/rootwork-icon.png` — 512×512 homescreen/PWA icon with the canonical `#AFE2FF` background.

Do not use the homescreen icon inside the app UI.

## Launch motion

The splash follows the approved mockup: canonical blue background, static subtle concentric rings, centered mark, wordmark and tagline, then a short indigo loading bar with `Đang khởi động...`. No bounce, pulse, halo burst, logo morph, blur, drop-shadow, or scale overshoot.

Reduced-motion preferences collapse the transition without decorative animation.
